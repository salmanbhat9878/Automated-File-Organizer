Automated File Organizer 📁

Project Description

Automated File Organizer is a Python-based application that automatically organizes files into different folders based on their file types.

Features

- Organize files by category
- Preview files using Dry Run
- Move files automatically
- Handle duplicate filenames
- Create category folders
- Error handling
- Activity logging
- Interactive menu system

Technologies Used

- Python
- pathlib
- shutil
- logging

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

"python file-organizer.py"

5. Select an option from the menu.
6. Enter source and target folder paths.

Menu Options

1. Preview Files (Dry Run)
2. Organize Files
3. Exit

File Categories

- Images
- Documents
- Videos
- Audio
- Archives
- Code
- Others
